# إكزامكس - رصد الدرجات في نظام نور

إضافة لمتصفح Chrome تساعد المعلمين على استيراد درجات اختبارات إكزامكس إلى صفحة رصد الدرجات في نظام نور.

## الإمكانيات

- استيراد ملفات Excel وCSV المصدّرة من إكزامكس.
- لصق درجات «نسخ لنور» مباشرة من الحافظة أو إدخال البيانات يدويًا.
- مطابقة الدرجات بالطلاب باستخدام رقم الهوية أو الاسم.
- استيراد الدرجات إلى الصفحة الحالية فقط.
- تصفير درجة عمود محدد في الصفحة الحالية.
- رصد الطالب الغائب بدرجة صفر عند تفعيل الخيار المناسب.
- حفظ حالة الشريط والإعدادات محليًا داخل المتصفح.

## المتطلبات

- متصفح يعتمد على Chrome أو Microsoft Edge أو متصفح كروميوم آخر.
- حساب نظام نور مفعّل للمستخدم.
- الوصول إلى صفحة رصد الدرجات المعتمدة في الإضافة.

## التثبيت للتطوير

1. افتح صفحة الإضافات:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
2. فعّل **وضع المطور**.
3. اختر **تحميل الإضافة غير المحزومة**.
4. اختر مجلد المشروع `examix-extension`.

## الاستخدام

1. افتح صفحة رصد الدرجات في نظام نور.
2. افتح شاشة تقارير إكزامكس واستخدم إما:
   - تصدير ملف Excel أو CSV، أو
   - زر «نسخ لنور».
3. عد إلى صفحة نور واختر مربع الدرجة المطلوب.
4. افتح شريط إكزامكس وحدد المصدر:
   - **استيراد ملف إكسل المصدّر**، أو
   - **لصق درجات نسخ لنور**.
5. راجع المطابقة والنتائج، ثم نفّذ الاستيراد.

## هيكل المشروع

```text
manifest.json
content.js
icons/
  icon16.png
  icon32.png
  icon48.png
  icon128.png
```

## خصوصية البيانات

- تعمل الإضافة داخل نطاق صفحة نظام نور المحدد في `manifest.json`.
- تُقرأ بيانات الدرجات والطلاب من الملف أو الحافظة التي يختارها المستخدم.
- لا ترسل الإضافة البيانات إلى خادم خارجي أو خدمة تحليل.
- تُحفظ إعدادات واجهة الإضافة وحالتها مؤقتًا أو محليًا في تخزين المتصفح.

## الجاهزية لمتجر Chrome

الحزمة المضمّنة للرفع هي `examix-extension-store.zip`.

تحتوي النسخة الجاهزة على Manifest V3 والأيقونات وأكواد الإضافة اللازمة لرفقها بصفحة متجر إضافات Chrome.
